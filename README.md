# 学生报考信息确认系统

CAIE 考试报考信息确认系统：学生核对本人学籍档案 → 勾选报考科目与单元 → 线上确认；教务后台处理纠错工单、导出报考汇总。

## 在线演示（GitHub Pages）

访问仓库对应的 Pages 地址即可打开**公开演示页**。

> 演示页运行在「离线演示模式」：完整流程都可以操作（身份验证、信息核对、纠错工单、科目选择、签名提交、教务后台、三件套导出），但**所有数据只保存在访客自己的浏览器 localStorage 中，不会上传、不会被教务收到**。页面内 14 名学生均为虚构示例数据。
>
> 体验账号：班级 `IG1` / 姓名 `张思远` / 出生日期 `2009-03-12`。
>
> 底部「教务后台（本机演示）」无需口令，可直接查看演示数据。

## 正式使用：跑完整服务端

GitHub Pages 是静态托管，无法运行 Node 服务，因此**不能用于真实收集学生提交**。正式报考需要一台能跑 Node 的机器（校内常开电脑 / 云服务器均可）。

```bash
cd src
node server.js
# 本机：http://localhost:8080
# 局域网：http://<服务器IP>:8080
```

Windows 用户也可直接双击 `src/启动服务.bat`。

- 首次运行会自动生成 `src/data/`（考试季、示例名单、后台口令 `exam2026`）
- **正式使用前务必修改 `src/data/admin.json` 里的口令**，改完重启服务
- 教务后台在页面底部，可管理考试季、导入名单、处理纠错、导出 CSV
- 每个考试季单独一个 `src/data/seasons/<编号>.json`，直接复制即可备份

数据文件含学生个人信息与后台口令，**已通过 `.gitignore` 排除，不会上传到本仓库**。

## 目录结构

| 路径 | 说明 |
|---|---|
| `index.html` | GitHub Pages 静态演示页（由 `src/public/index.html` 改造，强制离线演示 + 演示提示横幅 + 禁止搜索引擎索引） |
| `src/public/index.html` | 正式前端单页，连接服务端 API，无服务时自动退回本机演示 |
| `src/server.js` | 零依赖 Node 服务端，HTTP + JSON 文件存储 |
| `src/使用与部署说明.md` | 日常使用、考试季管理、三种上云方式与合规提醒 |
| `src/启动服务.bat` | Windows 一键启动 |

## 服务端接口概要

| 接口 | 用途 |
|---|---|
| `GET /api/boot` | 学生端配置（**不含学生名单**） |
| `POST /api/verify` | 姓名 + 出生日期服务端比对 |
| `POST /api/push` | 学生写回本人记录 / 工单 |
| `POST /api/admin/login`、`GET /api/admin/state`、`POST /api/admin/save` | 教务登录与数据读写 |
| `POST /api/admin/season` | 考试季切换、新建、名单导入、归档 |

安全设计：学生名单不下发浏览器；同一 IP 连续 3 次出生日期验证失败锁定 15 分钟并告警；提交后学生不可自行修改，变更须经教务纠错工单。

## 合规提醒

姓名、性别、出生日期属于个人信息。上公有云或公网托管前，请先确认学校是否允许。若不允许，使用校内局域网常开电脑即可，功能完全一致。正式对外服务建议配置 HTTPS。
